SIMTELE-RISK: análisis dinámico de seguridad en transporte por cable

Cuatro casos de estudio modelados matemáticamente: detención de emergencia, deterioro mecánico, oscilaciones por viento y reconstrucción de sensores. Cada uno incluye sus fórmulas, sus métodos numéricos, la entrada de parámetros y los gráficos. Todos los datos son sintéticos y de uso educativo.

01 · Resumen ejecutivo

Objetivos y alcance

La plataforma formula los modelos matemáticos de los cuatro casos de estudio, resuelve los sistemas lineales asociados, evalúa su convergencia y sensibilidad, y reporta los errores con una teoría de errores transversal.

Objetivo general

Modelar la seguridad dinámica de una cabina de transporte por cable y evaluar la exactitud y el condicionamiento de los métodos numéricos empleados.

Objetivos específicos

  • Formular y resolver los modelos de frenado, deterioro, oscilación y calibración.
  • Calcular errores absolutos, relativos, residuales y el número de condición κ₂.
  • Comparar LU, Jacobi, Gauss-Seidel y Gradiente Conjugado en tres escenarios.

Naturaleza de los datos

Parámetros sintéticos e hipotéticos, inspirados en sistemas urbanos de transporte por cable (como Mi Teleférico en La Paz). No describen fallas ni datos operativos reales.

Pregunta central

¿Cuándo una cabina cumple la distancia de seguridad al frenar, cuándo se alcanza el umbral de inspección, cuándo la oscilación supera el límite de alerta y qué tan fiables son las calibraciones de sensores frente al ruido y al mal condicionamiento?

03 · Marco matemático

Ecuaciones de referencia

Resumen de los modelos y de las relaciones que se usan en los cálculos de cada módulo.

Módulo 1 · Frenado

dx/dt = v ,  dv/dt = −[ a(t) + c·v ]
Constante: t_det = v₀ / a₀ ,  d = v₀² / (2·a₀)
Hidráulico: v(t) = v₀ − a_max·[ t + (e^(−k·t) − 1)/k ]

Latencia: t_r = t_sensor + t_red + t_PLC + t_actuador. Cada segundo de latencia suma v₀ metros de recorrido.

Módulo 2 · Deterioro

D(t) = D₀ + α·t + β·t² = D_u
t* = 2(D_u − D₀) / ( α + √(α² + 4β(D_u − D₀)) )
dt*/dD_u = 1 / (α + 2β·t*)

La forma estable evita la cancelación catastrófica de la fórmula directa cuando β es pequeño.

Módulo 3 · Oscilaciones

ω = √(k/m) ,  ζ = c/(2mω) ,  ω_d = ω√(1−ζ²)
X(Ω) = F₀ / √((k − mΩ²)² + (cΩ)²)
(F₀/X)² = k² + (c² − 2km)Ω² + m²Ω⁴

La última forma es lineal en a = [k², c²−2km, m²], lo que permite calibrar m, k y c por mínimos cuadrados.

Módulo 4 · Sensores

p(r) = c₀ + c₁r + … + c_d·r^d
(VᵀV)·c = Vᵀ·y ,  V_ij = r_i^j
|E(x)| ≤ M/(n!) · |∏(x − x_i)|

Interpolación de Lagrange, Newton por diferencias divididas y spline cúbico natural.

Hipótesis de trabajo

  1. El modelo de frenado es unidimensional y no incluye balanceo ni elasticidad del cable.
  2. El indicador D(t) es adimensional e ilustrativo; β ≥ 0 modela un deterioro creciente.
  3. El viento es armónico puro; el caso resonante es el escenario de diseño más desfavorable.
  4. El ruido de medición es aditivo, de media cero y generado con semilla fija (reproducible).
04 · Módulo 1 · Detención de emergencia

Frenado con latencia de reacción

La orden de parada se convierte en frenado efectivo tras la latencia del sistema. La cabina conserva v₀ durante t_r y luego desacelera hasta el reposo. Se verifica que D_total ≤ D_seg.

Formulación

d_reacción = v₀ · t_r
Constante: d_frenado = v₀² / (2·a₀)
Hidráulico: v(t) = v₀ − a_max·[ t + (e^(−k·t) − 1)/k ]
Tangencial: v(t) = v₀·(1 − t/T)² (raíz doble en T)
D_total = v₀·t_r + d_frenado ≤ D_seg

Las tres variantes se integran con RK2 (Heun) y RK4. Con c = 0 se comparan con la solución analítica.

05 · Módulo 2 · Deterioro mecánico

Cruce del umbral de inspección

El indicador D(t) crece con un término lineal y otro cuadrático. El instante t* en que alcanza el umbral D_u define cuándo debe realizarse la inspección preventiva.

Formulación

D(t) = D₀ + α·t + β·t²
f(t) = D(t) − D_u = 0 ,  raíz positiva t* ≥ 0
t* = 2(D_u − D₀) / ( α + √(α² + 4β(D_u − D₀)) )
dt*/dD_u = 1/(α + 2β·t*) ,  κ_rel = (D_u/t*)·dt*/dD_u

06 · Módulo 3 · Oscilaciones por viento

Respuesta lateral de la cabina

Un sistema masa-resorte-amortiguador de un grado de libertad responde a una fuerza senoidal. La amplitud máxima se compara con el umbral de alerta A_lim, y la calibración recupera m, k y c a partir de mediciones.

Formulación

m·x'' + c·x' + k·x = F₀·sen(Ω·t)
X(Ω) = F₀ / √((k − mΩ²)² + (cΩ)²) ,  tan φ = cΩ/(k − mΩ²)
Resonancia: X_res = F₀ / (c·ω)
(F₀/X)² = k² + (c² − 2km)Ω² + m²Ω⁴

La simulación usa RK4 con h = 0.05 s y parte del reposo.

07 · Módulo 4 · Reconstrucción de sensores

Calibración y reconstrucción

Las lecturas brutas se ajustan con un polinomio por mínimos cuadrados. Luego, la señal se reconstruye en instantes ocultos mediante interpolación.

Calibración

p(r) = c₀ + c₁·r + … + c_d·r^d
(VᵀV)·c = Vᵀ·y ,  κ₂(A) = λ_max / λ_min

Si los nodos son distintos y m ≥ n, la matriz A = VᵀV es SPD. El uso de la base monomial sobre [0, 1] eleva sensiblemente el número de condición κ₂(A).

Pseudocódigo unificado

ResolverSistemaSPD(A, b, tol, max_iter, metodo)
  validar dim(A) = n x n y dim(b) = n
  si metodo = LU:
     Doolittle: U(i,j) = A(i,j) − Σ L(i,k)U(k,j)
                L(j,i) = (A(j,i) − Σ L(j,k)U(k,i)) / U(i,i)
     resolver L·y = b y U·x = y
  x ← 0 ; r ← b ; res ← ‖r‖₂/‖b‖₂
  mientras res > tol y k < max_iter:
     JACOBI:      x_i ← (b_i − Σ_{j≠i} A_ij·x_j) / A_ii
     GAUSS-SEIDEL: igual, usando valores ya actualizados
     CG:          α = rᵀr/(pᵀAp); x += αp; r −= αAp
                  β = r'ᵀr'/rᵀr; p = r' + βp
     si res > 1e100 o no finito: DIVERGIÓ
  devolver x, k, estado, historial

09 · Teoría de errores transversal

Calculadora de errores

Introduce un vector de referencia y su aproximación. Si eliges un sistema, también se calcula el residual y la cota κ₂·‖r‖/‖b‖. Si la referencia es nula no se divide: solo se reporta el error absoluto.

Resultados

Errores

E_abs = ‖x_ref − x̃‖
E_rel = E_abs / ‖x_ref‖
E% = 100·E_rel

Residual y condición

r = b − A·x̃
κ₂(A) = λ_max / λ_min
E_rel ≤ κ₂ · ‖r‖/‖b‖

Fuentes de error

  • Truncamiento: paso h en RK y grado de interpolación.
  • Datos: ruido gaussiano en las lecturas.
  • Redondeo: aritmética de doble precisión.
  • Convergencia: tolerancia o límite de iteraciones.
10 · Escenarios transversales

Normal, estrés y mal condicionado

Riesgo físico, alta exigencia numérica, mal condicionamiento y fallo de convergencia son conceptos distintos. Cada escenario se evalúa con los cuatro módulos.

Normal

Datos consistentes, matrices bien condicionadas y parámetros dentro del rango nominal.

Estrés

Exigencia física o de datos (velocidad alta, latencia crítica, ruido). El riesgo cambia, el algoritmo no.

Mal condicionado

Sensibilidad matemática extrema: κ muy alto, raíces dobles o resonancia con amortiguamiento mínimo.

Limitaciones del modelo

  • Datos sintéticos: umbrales (D_seg = 15 m, D_u, A_lim) y coeficientes son supuestos.
  • Modelo unidimensional: no incluye pendientes, elasticidad del cable ni balanceo de la cabina.
  • Deterioro determinista: no incluye fatiga cíclica ni mantenimiento correctivo.
  • Viento armónico: el espectro eólico real es de banda ancha; no hay no linealidad geométrica.
  • Ruido gaussiano: el ruido real puede tener deriva térmica y fallas no estacionarias.
